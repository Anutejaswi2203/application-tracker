# Application Tracker

This is a **Spring Boot-based Application Tracker**. It helps users track job applications, maintain a list of jobs they've applied to, and manage application statuses.

## Features
- Add new job applications (company name, position, status, etc.).
- View a list of all job applications.
- Extendable for future features like filtering or analytics.

## Tech Stack
- **Backend**: Spring Boot
- **Database**: H2 (in-memory database)
- **Build Tool**: Maven
- **Language**: Java
